# 十大排序分类

> 先按思想分类：比较排序 vs 非比较排序。面试重点：快排、归并、堆排。

---

```
                 排序算法
                     │
     ┌───────────────┴───────────────┐
     │                               │
 比较排序                      非比较排序
     │                               │
 冒泡排序    O(n²)              计数排序    O(n+k)
 选择排序    O(n²)              桶排序      O(n) 平均
 插入排序    O(n²)              基数排序    O(d(n+k))
 希尔排序    ~O(n^1.3)
 快速排序    O(nlogn) ★★★★★
 归并排序    O(nlogn) ★★★★★
 堆排序      O(nlogn) ★★★★★
```

---

# 一、冒泡排序（Bubble Sort）

## 思想

相邻比较，大的往后"冒泡"。每轮确定一个最大值到末尾。

```
[5 3 4 2] → [3 5 4 2] → [3 4 5 2] → [3 4 2 5]  第一轮，5归位
[3 4 2 5] → [3 4 2 5] → [3 2 4 5]              第二轮，4归位
[3 2 4 5] → [2 3 4 5]                            第三轮，3归位
```

## 代码

```cpp
void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;  // 已有序，提前结束 → O(n)
    }
}
```

## 复杂度

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(n) | O(n²) | O(n²) | O(1) | ✅ |

几乎不用，只用于教学。

---

# 二、选择排序（Selection Sort）

## 思想

每轮找到未排序部分的最小值，放到已排序末尾。

```
[5 4 3 2 1] → 找最小1 → [1 4 3 2 5]
[1 4 3 2 5] → 找最小2 → [1 2 3 4 5]
```

## 代码

```cpp
void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++)
            if (arr[j] < arr[minIdx]) minIdx = j;
        swap(arr[i], arr[minIdx]);
    }
}
```

## 复杂度

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(n²) | O(n²) | O(n²) | O(1) | ❌ |

交换次数少（每轮最多1次），但无论如何都要遍历完。不稳定（跨距离交换可能打乱顺序）。

---

# 三、插入排序（Insertion Sort）

## 思想

模拟打扑克牌：每拿到一张新牌，向前找到合适位置插入。

```
[3 5 | 2] → 2向前找 → [2 3 5]
```

## 代码

```cpp
void insertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

## 复杂度

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(n) | O(n²) | O(n²) | O(1) | ✅ |

数据**几乎有序时特别快**（最好 O(n)）。STL 中 `std::sort` 在小数据量时切换到插入排序。

---

# 四、希尔排序（Shell Sort）

## 思想

插入排序的升级版。不是一次移动一位，而是按 gap 分组：

```
gap = n/2 → 每组内插入排序 → gap/2 → ... → gap=1（即标准插入排序）
```

经过大 gap 的"粗调"，数据接近有序，最后一轮插入排序就很快。

## 复杂度

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(n) | ≈O(n^1.3) | O(n²) 与增量有关 | O(1) | ❌ |

实际速度不错。不稳定（跨组交换）。

---

# 五、快速排序（★★★★★）

**面试最重要的排序，必须能手写。**

## 思想

选一个 Pivot，比它小的放左边，大的放右边。然后左右递归。

```
[7 5 3 9 10 2]
 Pivot=7
[5 3 2] 7 [9 10]    ← partition 后，7 已经就位
然后对左右子数组递归
```

## 代码（Lomuto 分区，简洁版）

```cpp
int partition(vector<int>& arr, int lo, int hi) {
    int pivot = arr[hi];         // 选最后一个为 pivot
    int i = lo;                  // i 指向"比 pivot 小的最后一个元素的下一个位置"
    for (int j = lo; j < hi; j++) {
        if (arr[j] < pivot)
            swap(arr[i++], arr[j]);
    }
    swap(arr[i], arr[hi]);       // pivot 归位
    return i;
}

void quickSort(vector<int>& arr, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(arr, lo, hi);
    quickSort(arr, lo, p - 1);
    quickSort(arr, p + 1, hi);
}
```

## 复杂度

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(nlogn) | O(nlogn) | **O(n²)** | O(logn) 递归栈 | ❌ |

**最坏情况：** 数组已排序且每次选最后一个为 pivot → 递归树退化为链 → O(n²)。
**工程优化：** 随机选 pivot、三数取中、小数组切插入排序。

实际速度是所有排序中**最快的**（缓存友好，常数因子小）。

# 六、归并排序（★★★★★）

## 思想

一直二分到单元素，然后不断 Merge 两个有序子数组。

```
[5 3 8 1]
  二分: [5 3] [8 1]
        二分: [5] [3]  [8] [1]
           ↑ 单元素天然有序
Merge: [3 5] [1 8]
Merge: [1 3 5 8]
```

## 代码

```cpp
void merge(vector<int>& arr, int l, int m, int r) {
    vector<int> L(arr.begin() + l, arr.begin() + m + 1);
    vector<int> R(arr.begin() + m + 1, arr.begin() + r + 1);
    int i = 0, j = 0, k = l;
    while (i < L.size() && j < R.size())
        arr[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];
    while (i < L.size()) arr[k++] = L[i++];
    while (j < R.size()) arr[k++] = R[j++];
}

void mergeSort(vector<int>& arr, int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(arr, l, m);
    mergeSort(arr, m + 1, r);
    merge(arr, l, m, r);
}
```

## 复杂度

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(nlogn) | O(nlogn) | **O(nlogn)** | **O(n)** | ✅ |

**唯一稳定 + O(nlogn) 的排序。** 适合链表排序（不需要额外空间，改指针即可）。代价是需要 O(n) 额外空间。

# 七、堆排序（★★★★★）

## 思想

维护大顶堆（父节点 ≥ 子节点）。堆顶永远是最大值。

```
构建大顶堆 → 取堆顶放最后 → 重新调整 → 循环
建堆 O(n)，每次调整 O(logn)，共 n 次 → O(nlogn)
```

## 代码（核心）

```cpp
void heapify(vector<int>& arr, int n, int i) {
    int largest = i;
    int l = 2 * i + 1, r = 2 * i + 2;
    if (l < n && arr[l] > arr[largest]) largest = l;
    if (r < n && arr[r] > arr[largest]) largest = r;
    if (largest != i) {
        swap(arr[i], arr[largest]);
        heapify(arr, n, largest);
    }
}

void heapSort(vector<int>& arr) {
    int n = arr.size();
    // 建堆：从最后一个非叶节点开始
    for (int i = n / 2 - 1; i >= 0; i--) heapify(arr, n, i);
    // 排序：依次取堆顶
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]);
        heapify(arr, i, 0);
    }
}
```

## 复杂度

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(nlogn) | O(nlogn) | **O(nlogn)** | **O(1)** | ❌ |

**唯一 O(1) 额外空间 + O(nlogn) 的排序。** 适用于内存紧张的场景（如嵌入式）。实际速度不如快排（跳跃访问，缓存不友好）。

---

# 八、计数排序（Counting Sort）

**非比较排序。** 统计每个值出现的次数，直接输出。

```
arr = [5 3 5 1]
count: 1→1次, 3→1次, 5→2次
输出: [1 3 5 5]
```

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(n+k) | O(n+k) | O(n+k) | O(k) | ✅ (倒序遍历保证) |

**限制：** 数据范围 k 不能太大（如年龄、分数、颜色值）。不能处理浮点数。

---

# 九、桶排序（Bucket Sort）

**非比较排序。** 把数据分散到多个桶，每个桶内部排序，最后合并。

```
成绩 0~100 → 分 10 个桶：0-9, 10-19, ..., 90-99
每个桶内用插入排序 → 合并
```

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(n) | O(n) | O(n²) 全进一个桶 | O(n+k) | 视内部排序而定 |

数据均匀分布时 O(n)，分布极端时退化为 O(n²)。

---

# 十、基数排序（Radix Sort）

**非比较排序。** 从低位到高位依次排序（每次用稳定排序，通常用计数排序）。

```
[329 457 657 839 436 720 355]
个位排序: [720 355 436 457 329 839 657]
十位排序: [720 329 436 839 355 457 657]
百位排序: [329 355 436 457 657 720 839]
```

| 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| O(d(n+k)) | O(d(n+k)) | O(d(n+k)) | O(n+k) | ✅ |

d = 最大位数，k = 基数（通常 10）。适合整数排序，不能处理浮点。

---

# 十种排序总结

| 排序 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|------|
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ |
| 插入 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 希尔 | O(n) | ≈O(n^1.3) | O(n²) | O(1) | ❌ |
| **快排** | O(nlogn) | O(nlogn) | O(n²) | O(logn) | ❌ |
| **归并** | O(nlogn) | O(nlogn) | O(nlogn) | O(n) | ✅ |
| **堆排** | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | ❌ |
| 计数 | O(n+k) | O(n+k) | O(n+k) | O(k) | ✅ |
| 桶排 | O(n) | O(n) | O(n²) | O(n+k) | 视情况 |
| 基数 | O(d(n+k)) | O(d(n+k)) | O(d(n+k)) | O(n+k) | ✅ |

# 选排序速记法

```
你需要稳定 + O(nlogn)     → 归并排序
你需要 O(1)额外空间        → 堆排序
你需要"一般情况最快"       → 快速排序（std::sort）
数据范围小（如年龄、分数） → 计数排序
数据几乎有序               → 插入排序
```

# 面试最爱问

### ① 为什么 `std::sort` 不直接用快速排序？

现代 STL 使用 **Introsort（内省排序）**：

```
快速排序 → 递归太深（超 2*logN）→ 切换堆排序 → 小数组（<16）→ 切换插入排序

保证最坏 O(nlogn)，同时保留快排的平均性能优势。
```

### ② 哪几个排序最坏仍然是 O(nlogn)？

**归并排序、堆排序、内省排序（std::sort）。** 快排不是（最坏 O(n²)）。

### ③ 稳定排序 vs 不稳定排序

**稳定（4个）：** 冒泡、插入、归并、基数
**不稳定（其余）：** 选择、希尔、快排、堆排

"稳定"意味着相等元素排序后保持原有相对顺序。多关键字排序时需要（如先按年龄排，再按姓名排）。

### ④ 游戏开发中最常用？

- `std::sort`（Introsort）—— 99% 的场景
- 小数组切插入排序（STL 内部已做）
- 特殊场景：计数/桶排序（如 Sprite 排序按 layer）
- 几乎不需要手写，但面试必考**快排、归并、堆排**这三个。
