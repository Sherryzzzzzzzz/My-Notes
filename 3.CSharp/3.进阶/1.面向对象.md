# 面向对象（OOP）四大支柱

面向对象编程（OOP）有四大核心特性：**封装、继承、多态、抽象**。很多资料只提前三个，但抽象（Abstraction）同样是必不可少的支柱。

---

## 1. 封装（Encapsulation）

将数据（字段）和行为（方法）捆绑在类内部，通过访问修饰符控制外部可见性，隐藏实现细节。

```csharp
public class BankAccount
{
    // 私有字段 —— 外部不可直接访问
    private decimal _balance;

    // 公共属性 —— 受控的访问入口
    public decimal Balance
    {
        get { return _balance; }
        private set
        {
            if (value < 0)
                throw new ArgumentException("余额不能为负");
            _balance = value;
        }
    }

    public string OwnerName { get; }  // 只读自动属性

    public BankAccount(string owner, decimal initialDeposit)
    {
        OwnerName = owner;
        Balance = initialDeposit;
    }

    public void Deposit(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentException("存款金额必须大于0");
        Balance += amount;
    }

    public bool Withdraw(decimal amount)
    {
        if (amount > Balance) return false;
        Balance -= amount;
        return true;
    }
}
```

**关键 C# 访问修饰符**：
| 修饰符 | 访问范围 |
|---|---|
| `public` | 无限制 |
| `private` | 仅当前类内部 |
| `protected` | 当前类 + 派生类 |
| `internal` | 当前程序集内 |
| `protected internal` | 当前程序集 OR 派生类 |
| `private protected` | 当前程序集内 AND 派生类 |

## 2. 继承（Inheritance）

子类复用父类的属性和方法，并可以扩展或修改行为。

```csharp
// 基类
public class Animal
{
    public string Name { get; set; }
    public int Age { get; set; }

    public Animal(string name, int age)
    {
        Name = name;
        Age = age;
    }

    public virtual void MakeSound()  // virtual = 允许子类重写
    {
        Console.WriteLine($"{Name} 发出了声音");
    }
}

// 派生类
public class Dog : Animal  // C# 只支持单继承
{
    public string Breed { get; set; }

    // 调用基类构造函数
    public Dog(string name, int age, string breed) : base(name, age)
    {
        Breed = breed;
    }

    public override void MakeSound()  // override = 重写基类方法
    {
        Console.WriteLine($"{Name} (一只{Breed}): 汪汪！");
    }
}

// 使用
var dog = new Dog("旺财", 3, "金毛");
dog.MakeSound();  // 输出: 旺财 (一只金毛): 汪汪！
```

> **`virtual` / `override` / `abstract` / `new` 的区别**：
> - `virtual` → 基类声明"可以被子类重写"
> - `override` → 子类"重写"基类虚方法（多态）
> - `abstract` → 基类"不提供实现，强制子类实现"
> - `new` → 子类"隐藏"基类同名方法（非多态，不推荐）

## 3. 多态（Polymorphism）

同一个接口，不同实现。基于继承，通过基类引用调用派生类的重写方法。

```csharp
// 多态：基类引用指向派生类对象
Animal[] zoo = new Animal[]
{
    new Dog("旺财", 3, "金毛"),
    new Cat("咪咪", 2, "橘猫"),
    new Dog("大黄", 1, "田园犬")
};

foreach (var animal in zoo)
{
    animal.MakeSound();  // 运行时根据实际类型调用对应方法！
}
// 输出:
// 旺财 (一只金毛): 汪汪！
// 咪咪 (一只橘猫): 喵喵~
// 大黄 (一只田园犬): 汪汪！
```

```csharp
public class Cat : Animal
{
    public string Color { get; set; }

    public Cat(string name, int age, string color) : base(name, age)
    {
        Color = color;
    }

    public override void MakeSound()
    {
        Console.WriteLine($"{Name} (一只{Color}): 喵喵~");
    }
}
```

## 4. 抽象（Abstraction）—— 第四支柱

隐藏复杂的实现细节，只暴露必要的接口。在 C# 中通过 **抽象类（abstract class）** 和 **接口（interface）** 实现。

### 抽象类

```csharp
// 抽象类：不能被实例化，可以包含实现和非实现方法
public abstract class Shape
{
    public string Name { get; }

    protected Shape(string name) => Name = name;

    // 抽象方法：无实现，强制子类实现
    public abstract double GetArea();

    // 非抽象方法：有默认实现
    public virtual void Draw()
    {
        Console.WriteLine($"绘制 {Name}，面积: {GetArea():F2}");
    }
}

public class Circle : Shape
{
    public double Radius { get; }
    public Circle(double r) : base("圆形") => Radius = r;
    public override double GetArea() => Math.PI * Radius * Radius;
}

public class Rectangle : Shape
{
    public double Width { get; }
    public double Height { get; }
    public Rectangle(double w, double h) : base("矩形") => (Width, Height) = (w, h);
    public override double GetArea() => Width * Height;
}
```

**抽象类 vs 接口**：
| | 抽象类 | 接口 |
|---|---|---|
| 实例化 | ❌ 不能 | ❌ 不能 |
| 包含字段 | ✅ | ❌（只有属性/方法签名） |
| 包含实现 | ✅ | C# 8+ 可含默认实现 |
| 多继承 | ❌ 只能单继承 | ✅ 可实现多个接口 |
| 语义 | "是什么"（is-a） | "能做什么"（can-do） |

## 面试常问

> **Q: 面向对象四大支柱分别解决什么问题？**
> **封装**：隐藏内部状态，提供受控访问 → 安全
> **继承**：复用代码，建立 "is-a" 关系 → 减少重复
> **多态**：统一接口处理不同对象 → 灵活扩展
> **抽象**：只暴露必要信息，隐藏复杂度 → 简化心智负担

> **Q: 什么时候用抽象类，什么时候用接口？**
> 抽象类用于有共同实现的基类场景（如 `Shape` 有 `Name` 字段和 `Draw()` 默认实现）；接口用于跨层次的能力契约（如 `IDisposable`、`IEnumerable<T>`），且一个类可以实现多个接口。
