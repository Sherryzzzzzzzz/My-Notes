# 深拷贝与浅拷贝

在 C# 中，**深拷贝**（Deep Copy）和**浅拷贝**（Shallow Copy）是两种不同的对象复制方式。

核心区别在于对引用类型字段的处理方式以及复制后的对象独立性。

**浅拷贝**：适用于对象结构简单且引用类型字段无需独立修改的场景（如临时快照）。

**深拷贝**：适用于需要完全隔离的场景（如多线程操作、持久化备份）。

------

### **浅拷贝（Shallow Copy）**

- **定义**：浅拷贝仅复制对象本身的值类型字段和引用类型字段的**引用**（即内存地址），而不复制引用类型字段指向的实际对象。
- **特点**

原始对象和副本共享引用类型字段的实际数据。

修改副本中的引用类型字段（如修改属性值）会影响原始对象，反之亦然。

- **实现方式**

​		使用 `MemberwiseClone()` 方法（继承自 `System.Object`），这是 C# 默认提供的浅拷贝机制。

​	直接赋值（如 `var copy = original;`）也是浅拷贝的一种形式。

- **示例**

> ⚠️ 注意：`string` 是 immutable 类型，赋值 `shallowCopy.Name = "Bob"` 实际上是让 `shallowCopy.Name` 指向新字符串对象，不会影响 `original.Name`。正确演示浅拷贝应使用**可变引用类型**（如内嵌类、`List<T>` 等）。

```csharp
public class Person
{
    public string Name;                  // 值语义（string 不可变，行为类似值类型）
    public List<string> Skills;          // 可变引用类型 —— 这才是浅拷贝的关键！
}

var original = new Person
{
    Name = "Alice",
    Skills = new List<string> { "C#", "Unity" }
};

// 浅拷贝：Skills 引用被共享
var shallowCopy = (Person)original.MemberwiseClone();
shallowCopy.Name = "Bob";               // ✅ 不影响 original（Name 是新字符串）
shallowCopy.Skills.Add("Blender");      // ⚠️ 影响 original！因为 Skills 指向同一个 List

Console.WriteLine(original.Name);       // 输出 "Alice"（未受影响）
Console.WriteLine(original.Skills.Count); // 输出 3（被影响了！）
```

------

### **深拷贝（Deep Copy）**

- **定义**：深拷贝会递归复制对象及其所有引用类型字段指向的实际对象，生成一个完全独立的副本。
- **特点**

- 原始对象和副本不共享任何引用类型字段的数据。
- 修改副本不会影响原始对象，反之亦然。

- **实现方式**

- **手动实现**：为每个引用类型字段创建新实例并赋值（适用于简单对象）。
- **序列化**：通过二进制、JSON 或 XML 序列化与反序列化（需对象标记为 `[Serializable]`）。
- **反射**：递归复制所有字段（包括私有字段）。
- **第三方库**：如 `AutoMapper`、`DeepCloner`（高性能）。

- **示例**（使用 System.Text.Json，.NET 现代推荐方式）

```csharp
using System.Text.Json;

var original = new Person
{
    Name = "Alice",
    Skills = new List<string> { "C#", "Unity" }
};
var json = JsonSerializer.Serialize(original);
var deepCopy = JsonSerializer.Deserialize<Person>(json)!;

deepCopy.Name = "Bob";
deepCopy.Skills.Add("Blender");

Console.WriteLine(original.Name);         // 输出 "Alice"（未受影响）
Console.WriteLine(original.Skills.Count); // 输出 2（未受影响）
```

- **手动深拷贝示例**（不依赖序列化）

```csharp
public class Person
{
    public string Name;
    public List<string> Skills;

    // 手动深拷贝
    public Person DeepCopy()
    {
        return new Person
        {
            Name = this.Name,                           // string 不可变，直接赋值即可
            Skills = new List<string>(this.Skills)       // 创建新 List
        };
    }
}
```

- **补充：`ICloneable` 接口**

.NET 提供了 `ICloneable` 接口用于标记可克隆类型，但它有设计缺陷：不明确是深拷贝还是浅拷贝。实际项目中建议自己定义 `DeepCopy()` 方法。

- **补充：C# 9+ `record` 类型**

```csharp
// record 内置了值相等和 with 表达式（浅拷贝 + 修改）
public record PersonRecord(string Name, List<string> Skills);

var p1 = new PersonRecord("Alice", new List<string> { "C#" });
var p2 = p1 with { Name = "Bob" };  // 浅拷贝 + 修改 Name
// 注意：Skills 仍然是共享的！record 的 with 也是浅拷贝
```

------

### **关键区别总结**

| **对比项**       | **浅拷贝**                 | **深拷贝**                           |
| ---------------- | -------------------------- | ------------------------------------ |
| **引用类型处理** | 复制引用（共享数据）       | 递归复制实际对象（独立数据）         |
| **性能**         | 高效（仅复制引用）         | 较低（需递归或序列化）               |
| **适用场景**     | 临时副本、无需独立性的场景 | 需完全隔离的场景（如缓存、线程安全） |
| **实现复杂度**   | 简单（`MemberwiseClone`）  | 复杂（需手动或序列化）               |
