# List原理

List 内部由三个核心字段组成：

```csharp
public class List<T>
{
    private T[]     _items;    // 存储元素的内部数组
    private int     _size;     // 当前元素数量
    private int     _version;  // 版本号（迭代时检测集合是否被修改）
    // ...
}
```

默认初始容量为 0（或 4），当添加元素时内部数组不够用会触发扩容。

## 扩容机制

```csharp
// EnsureCapacity 核心逻辑（简化）
void EnsureCapacity(int min)
{
    if (_items.Length < min)
    {
        // 新容量 = 旧容量 * 2（倍增策略）
        int newCapacity = _items.Length == 0 ? 4 : _items.Length * 2;
        T[] newItems = new T[newCapacity];
        Array.Copy(_items, newItems, _size);
        _items = newItems;  // 旧数组被 GC 回收
    }
}
```

扩容方式为 2 的指数（4, 8, 16, 32...），如果元素数量有 65 个，则扩容到 128，造成约 60 个元素的内存浪费。

> **最佳实践**：如果预先知道元素数量，用 `new List<T>(capacity)` 预分配容量避免频繁扩容。

## Add 函数

```csharp
public void Add(T item)
{
    if (_size == _items.Length)
        EnsureCapacity(_size + 1);  // 扩容
    _items[_size++] = item;
    _version++;  // foreach 迭代时检测用的版本号
}
// 时间复杂度：均摊 O(1)
```

## Remove / RemoveAt 函数

```csharp
public bool Remove(T item)
{
    int index = Array.IndexOf(_items, item, 0, _size);
    if (index >= 0) { RemoveAt(index); return true; }
    return false;
}

public void RemoveAt(int index)
{
    _size--;
    if (index < _size)
        Array.Copy(_items, index + 1, _items, index, _size - index);
    _items[_size] = default(T);  // 释放引用
    _version++;
}
// 时间复杂度：O(n)（需要搬移后续元素）
```

## Insert 函数

```csharp
public void Insert(int index, T item)
{
    if (_size == _items.Length) EnsureCapacity(_size + 1);
    if (index < _size)
        Array.Copy(_items, index, _items, index + 1, _size - index);
    _items[index] = item;
    _size++;
    _version++;
}
// 时间复杂度：O(n)
```

## Clear 函数

```csharp
public void Clear()
{
    Array.Clear(_items, 0, _size);  // 释放引用，帮助 GC
    _size = 0;
    _version++;
}
```

## Contains 函数

```csharp
public bool Contains(T item)
{
    return Array.IndexOf(_items, item, 0, _size) >= 0;
}
// 时间复杂度：O(n)（线性查找）
```

## ToArray 函数

```csharp
public T[] ToArray()
{
    T[] result = new T[_size];
    Array.Copy(_items, result, _size);
    return result;
}
```

## Sort 函数

内部使用 `Array.Sort()`，采用**内省排序（Introspective Sort）**：快速排序 + 堆排序 + 插入排序的混合，时间复杂度 O(n log n)。
